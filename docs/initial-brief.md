# Project Brief

Personal travel site for a backpacking trip across Italy (August 13–30, 2026).

## Goal

A lightweight bilingual website to share the journey with friends and family — an interactive map showing the route and a photo gallery updated on the go from a phone.

## Requirements

- **Interactive map** with the trip route (Paris → Milan → Naples → Palermo → Milan → Paris)
- **Photo upload** from the field with geolocation (manual pin or GPS) and bilingual captions
- **Password-protected upload** — no user accounts, just a shared password
- **Bilingual** — French (default) and English, switchable via URL
- **Self-hosted** on a Raspberry Pi running Coolify, behind a Cloudflare DNS tunnel
